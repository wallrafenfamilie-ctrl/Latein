# Latin Quest – Leni Edition 1.0.2

Installierbare Offline-PWA für GitHub Pages. Neue Funktion: Stammformen-Test (Präsens, Perfekt, Supinum) mit drei separaten Eingaben, Korrektur und eigenem Lernfortschritt. Die Stammformen erscheinen beim gewöhnlichen Vokabeltest erst nach Abgabe.

**Daten:** Der lokale Speicherschlüssel `latinquest-leni-v1` und die bisherigen Vokabel-IDs bleiben unverändert. Backup vor dem Update empfohlen.

**Inhalte:** Die PDFs bis Lektion 24 liegen vor, aber diese Ausgabe enthält nur die bisherige kleine Vokabelauswahl aus Lektion 23 und 24. Nicht vollständig geprüftes Material wird nicht als fertig bezeichnet. Die Stammformen-Daten sind weiterhin mit den Buchseiten abzugleichen.

**Veröffentlichung:** Dateien ins Repository-Root laden, `main` → GitHub Pages `/ (root)`.
