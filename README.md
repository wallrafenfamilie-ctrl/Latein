# Latin Quest – Leni Edition (GitHub-Pages-PWA)

## Veröffentlichung
1. Auf GitHub ein neues **öffentliches** Repository `latin-quest-leni` erstellen (oder ein bestehendes verwenden).
2. Die Dateien **aus diesem Ordner** direkt ins Stammverzeichnis des Repositories hochladen (nicht die ZIP-Datei als einzelne Datei).
3. Unter **Settings → Pages → Build and deployment** als Source **Deploy from a branch**, Branch `main`, Folder `/(root)` wählen und speichern.
4. GitHub zeigt nach der Veröffentlichung die HTTPS-Adresse an, normalerweise `https://BENUTZERNAME.github.io/latin-quest-leni/`.
5. Auf Lenis Android-Gerät diese Adresse in Chrome öffnen und über das Browsermenü **App installieren** / **Zum Startbildschirm hinzufügen** wählen.

## Lernmaterial / Prüfstand
Die 7 hochgeladenen Pontes-PDFs decken Lektionen 3–24 ab. Die Fotos sind Bild-PDFs, teils seitlich. **Diese Ausgabe enthält nicht alle Vokabeln!** Manuell geprüfte Auswahl: Lektionen 23 und 24, und drei Übersetzungsbeispiele aus Lektion 24. Alle anderen Lektionen werden sichtbar als `In Arbeit` geführt. Für eine vollständige Version müssen die weiteren Vokabellisten und Grammatikaufgaben Seite für Seite transkribiert und geprüft werden.

## Spielstände / Updates
Speicherung im `localStorage` unter `latinquest-leni-v1`. Bei Updates derselben GitHub-Pages-URL bleibt der Speicher in der Regel erhalten. Bei Domain-/Browserwechsel oder Löschen der Website-Daten ist eine Backup-Datei notwendig. Backup exportieren unter **Sicherung**. Ältere v0.2.1-Daten können ein abweichendes Format haben und sind **nicht garantiert automatisch migrierbar**. Die alte App und deren Backup behalten. Niemals den Speicher löschen, bevor der Import geprüft ist.

## Offline-Übersetzungen
Nur exakte hinterlegte, nach Groß-/Kleinschreibung und Satzzeichen normalisierte Varianten werden automatisch erkannt. Alternative korrekte Übersetzungen werden **nicht zuverlässig** automatisch erkannt und müssen anhand der Musterlösung selbst kontrolliert werden.

## Datenschutz
Kein Server, keine Anmeldung, keine Analyse-Dienste. Lernfortschritt liegt lokal im Browser. Bei der Veröffentlichung auf einem öffentlichen GitHub-Repository keine privaten Fotos, Namen über `Leni` hinaus oder Spielstandsdateien hochladen.
